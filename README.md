# Приложение для отслеживания статистики гонщиков и гоночных команд мировых чемпионатов.

## Краткое описание
Web-Приложение, позволяющее отслеживать и сравнивать статистику отдельных гонщиков и команд в различных мировых чемпионатах.
Гонщиков и команды можно сравнивать и добавлять в избранное.
В качестве "приятного бонуса" в приложении представлена судоку-подобная игра, в которой необходимо по заданным по столбцам и строкам критериям подбирать подходящих гонщиков/команд/трассы.

## Предметная область
Предметная область - мировые гоночные чемпионаты, гонщики, команды и автомобили, выступающие в них, 
а также трассы, принимающие заезды этих чемпионатов.

|----------------|-------------------------------|------------------------|----------------------|-----------------------|
| fiawec         | -                             | -                      | -                    | -                     |
| formula1       | -                             | +                      | -                    | +                     |
| drivergridgame | -                             | -                      | +                    | -                     |
| 51gt3          | +                             | +                      | -                    | -                     |
| IMSA           | -                             | -                      | -                    | -                     |


В основном, у каждого чемпионата свои ресурсы, поэтому сравнение гонщиков из разных чемпионатов весьма проблематично.

## Целесообразность и актуальность
В последние годы популярность автоспорта как в России, так и во всем мире заметно возрасла. На данный момент нет единого
ресурса, содержащего всю необходимую информацию о самых крупных мировых чемпионатах.

## Роли
 - Гость - неавторизованный пользователь, который может просматривать статистику и выполнять сравнения.
 - Авторизованный пользователь - тот же функционал, но с возможностью добавления гонщиков/команд в избранное.
 - Администратор - осуществляет обновление базы данных результатов, а также исправляет неточности и ошибки в данных.

## Пользовательские сценарии
### Просмотр статистики
 - Пользователь открывает приложение
 - Выбирает нужный пункт меню
 - Выбирает какую статистику хочет просмотреть
 - Вводит фильтры статистики (по гонщику, команде и т.п.)

### Сравнение статистики
 - Пользователь открывает приложение
 - Выбирает нужный пункт меню
 - Выбирает команды/гонщиков для сравнения

### Добавление в избранное
 - Пользователь открывает приложение
 - Выбирает нужный пункт меню
 - Вводит интересующего гонщика/команду

### Судоку-подобная игра
 - Пользователь открывает приложение
 - Выбирает нужный пункт меню
 - Вводит подходящие значения на пересечениях условий
